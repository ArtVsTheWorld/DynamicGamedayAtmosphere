# Dynamic Gameday Atmosphere
By Ace | Version 1.20.1 | Offline CFB 27

Changing crowds, bigger gameday atmosphere and more post-play replays.

## Install or update

1. Close the game and MMC Mod Manager.
2. Copy `Plugins/DynamicGamedayAtmosphere.dll` from this ZIP into MMC's `Plugins` folder. Replace the previous copy.
3. Open MMC and launch the game through it.

Keep your existing settings file. Supporting files and settings updates are handled automatically.

## A few things to know

- Crowd percentages refer to the attendance the game originally chose, rather than the stadium's total capacity.
- Normal crowd changes wait for play selection or breaks.
- Arrival and departure timing adjusts to your quarter length. The feature list uses 12-minute quarters for examples.
- Full-screen replays keep the game's normal skip control.

Read `FEATURES.md` for the full explanation of attendance, crowd audio, replays and resumed games.

Settings: `Plugins/DynamicGamedayAtmosphere.ini`

Logs and status: `Plugins/DynamicGamedayAtmosphere/Logs/`

Logs clear at about 2 MB by default. Game updates may require a plugin update.
